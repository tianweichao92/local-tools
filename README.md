# local-tools

Public, local-first utilities for macOS, Windows, and Linux. Support is declared per tool; this repository does not imply every tool runs on every platform.

| Tool | macOS | Windows | Linux |
| --- | --- | --- | --- |
| [Claude Remote Control autostart](tools/claude-rc-autostart/README.md) | Supported | Not yet supported | Not yet supported |

Each tool has its own installation instructions and safety notes. The current release contains only the macOS implementation of Claude Remote Control autostart.
